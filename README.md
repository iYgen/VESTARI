# Vestari

Почтовый клиент для Android: несколько ящиков (Mail.ru, Яндекс, Gmail, Outlook, Рамблер, любой IMAP), без рекламы,
с автоматической раскладкой писем по папкам «Чеки», «Скидки», «Билеты», «Рассылки», «Госписьма», «Письма себе»
и своими папками.

## Что умеет
- Несколько ящиков: переключение в шторке аккаунтов или режим «Все ящики».
- Папки-категории: письма раскладываются автоматически, их можно перенести вручную (удержание на письме),
  создавать свои папки с иконкой, менять порядок перетаскиванием, переименовывать и удалять (с отменой).
- Свайп вправо — прочитано/непрочитано, влево — удалить (с отменой). Звёздочка — пометка на сервере.
- Чтение писем без загрузки картинок по умолчанию (защита от трекеров рассылок), ответ и новое письмо.
- Фоновая проверка почты и уведомления (раз в ~15 минут).
- Цветовые гаммы (Лаванда, Vestari, Океан, Мята, Закат, Графит) и тёмная тема.
- Анимации: пружинные нажатия, переход «карточка → письмо», плавная смена темы.
- Автообновление из GitHub Releases.

Пароли хранятся только на телефоне, зашифрованные ключом Android Keystore. Почта загружается напрямую с серверов
по IMAP/SMTP. Для Mail.ru, Яндекса и Gmail нужен **пароль для внешнего приложения** (подсказка есть на экране
добавления ящика).

## Сборка
**Установка:** скачайте [Vestari.apk](https://github.com/iYgen/VESTARI/raw/main/Vestari.apk) и откройте на телефоне (разрешите установку из этого источника).

Для сборки нужны JDK 17+ и Android SDK 35.
```
gradlew assembleRelease
```
APK: `app/build/outputs/apk/release/app-release.apk`.

## Ключ подписи
Папка `signing/` (в git не попадает) содержит ключ `vestari-release.jks` и пароль к нему в `keystore.properties`.
**Сохраните её копию в надёжном месте.** Все версии должны быть подписаны одним ключом, иначе Android не даст
поставить обновление поверх установленного приложения.

## Автообновления через GitHub
1. Создайте **публичный** репозиторий на GitHub и запушьте проект.
2. В репозитории: Settings → Secrets and variables → Actions → New repository secret:
   - `VESTARI_KEYSTORE_BASE64` — содержимое ключа в base64:
     `powershell -c "[Convert]::ToBase64String([IO.File]::ReadAllBytes('signing\vestari-release.jks'))"`
   - `VESTARI_KEYSTORE_PASSWORD` — значение `storePassword` из `signing/keystore.properties`.
3. Выпуск версии:
   ```
   git tag v0.1.0
   git push origin v0.1.0
   ```
   GitHub Actions прогонит тесты, соберёт подписанный `vestari-0.1.0.apk` и опубликует релиз.
4. Первую версию поставьте на телефон из раздела Releases. Дальше приложение само проверяет новые релизы
   при запуске (и вручную: Профиль → Обновления), скачивает APK и открывает установщик.

Адрес репозитория для обновлений CI подставляет сам. Для локальных сборок он задаётся в `gradle.properties`
(`vestari.updateRepo=owner/repo`).

## Иконка
Иконка нарисована векторами по логотипу: `app/src/main/res/drawable/ic_launcher_background.xml` (градиент)
и `ic_launcher_foreground.xml` (конверт).
